# 🏎️ Formula 1 World Championship (1950–2024) — SQL Project

## 📌 Overview

This project analyzes **Formula 1 World Championship data from 1950 to 2024 using SQL**. It focuses on drivers, constructors, races, circuits, results, and qualifying performance.

## 🎯 Objectives

* Analyze driver and constructor performance
* Study race and qualifying results
* Identify top-performing drivers and constructors
* Analyze season-wise and circuit-wise trends
* Apply SQL concepts from basic to advanced

## 📊 Dataset

**World Championship (1950–2024)**

* **38,650 records**
* 6 tables:

  * Drivers
  * Constructors
  * Circuits
  * Races
  * Results
  * Qualifying

## 🛠️ SQL Concepts Used

* DDL & DML
* DQL & SQL Clauses
* Operators & Aggregate Functions
* String & Conditional Functions
* Joins
* Window Functions
* Subqueries
* Views

## 💡 Key Analysis

* Driver and constructor rankings
* Total and cumulative points
* Race victories and finishing positions
* Qualifying performance
* Qualifying vs. race performance
* Historical circuit and season trends

## 🏁 Conclusion

The project demonstrates how SQL can be used to transform historical Formula 1 data into meaningful insights for **performance analysis and decision-making**.
